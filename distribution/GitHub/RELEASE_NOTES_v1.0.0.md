# DinKhon (দিনক্ষণ • বাংলা ক্যালেন্ডার) — v1.0.0

First stable public release of **DinKhon (`দিনক্ষণ • বাংলা ক্যালেন্ডার`)**, a 100% offline, privacy-first, open-source Bangladeshi Bangla and Gregorian calendar application for Android with an Apple-inspired Liquid Glass interface.

---

## ✨ Highlights in v1.0.0

- **Official 2019 Revised Bangladesh Bangla Academy Calendar**:
  - Accurate two-way conversion between **বঙ্গাব্দ (Bangla)** and **Gregorian (English)** calendars.
  - First 6 months (**বৈশাখ – আশ্বিন**): 31 days; **কার্তিক – মাঘ & চৈত্র**: 30 days; **ফাল্গুন**: 29 days (30 days in Gregorian leap years).
  - **পহেলা বৈশাখ (1 Boishakh)** always falls on **14 April**.
  - Automatic current-date detection in **`Asia/Dhaka` (`UTC+6`)**.
- **Instant `বাংলা | English` Mode Toggle**:
  - Preserves the exact selected real-world date while smoothly converting numerals, month grids, weekdays, and seasons.
- **Interactive Two-Way Date Converter & Quick Jump**:
  - Jump to or convert any historical or future Bangla or Gregorian date.
- **Liquid Glass UI & 60/120Hz Smooth Animations**:
  - Full support for **System (`সিস্টেম`)**, **Light (`সাদা`)**, and **Dark (`কালো`)** themes.
  - Interactive finger-follow month swiping and GPU-accelerated `graphicsLayer` transitions.
  - Universal Adaptive Icon + Android 13+ Material You `<monochrome>` Themed Icon support.
- **100% Offline, Ad-Free & Open Source (`Apache-2.0`)**:
  - Requests **zero Android permissions** (no `INTERNET` permission, no analytics, no trackers).

## 📦 Installation & Verification

1. Download the signed release APK (`dinkhon-v1.0.0-release.apk` / `app-release.apk`) attached to this release.
2. *(Optional)* Verify the SHA-256 checksum before installing:
   ```bash
   sha256sum app-release.apk
   ```
3. Open the APK on your Android device (`Android 8.0 / API 26+`) to install.
